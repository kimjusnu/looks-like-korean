# looks_like_korean

AI가 쓴 티가 나지 않는 한국어를 쓰게 돕는 Claude Code 스킬. 자기소개서, 제안서, 공문, 앱 화면 문구를 장르에 맞게 고치고, 고치는 동안 없는 사실을 지어내지 않는다.

## 설치

Claude Code에서:

```
/plugin marketplace add kimjusnu/looks_like_korean
/plugin install looks-like-korean@looks-like-korean
```

설치한 뒤 「이 자기소개서 AI 티 안 나게 고쳐 줘」처럼 요청하면 스킬이 동작한다. 파이썬 3.10 이상이 필요하다.

검사기만 따로 쓰려면 `pip install git+https://github.com/kimjusnu/looks_like_korean.git` 후 `looks-like-korean check 초안.md --genre self-intro`.

## Before → After

같은 요청을 AI 모델 네 곳에 보내 받은 원문이 **Before**, 그 원문을 Claude Code가 이 스킬로 고친 결과가 **After**다. 요청문과 원문 전체는 [`examples/`](examples/)에 있다. (2026-09-29, OpenCode Zen 무료 모델)
