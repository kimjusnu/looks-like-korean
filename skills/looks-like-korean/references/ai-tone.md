# AI 말버릇 목록

Claude·GPT 출력 90개에서 주제와 상관없이 되풀이된 표현을 틀로 묶은 것이다. 쓸 때 처음부터 피하고,
`check`가 잡으면 고친다. 측정 근거는 `docs/research/ai-tone.md`, 정규식은 `src/looks_like_korean/tone.py`.

- **경고**: 사람 글에서는 거의 안 나오고 AI 출력 여러 주제에서 반복된 것. 고친다
- **검토**: AI에 많지만 사람도 쓰는 것. 한 글에 여러 번이면 줄인다

## 대화 말버릇

| 등급 | 틀 | 고치는 방법 | 적용 장르 |
|---|---|---|---|
| 경고 | 치켜세우기·맞장구로 시작 (`TONE-FLATTER`) | 칭찬·맞장구 문장을 지우고 첫 문장에 바로 판단을 쓴다 | 대화 답변 |
| 경고 | 양쪽 다 맞다는 판정 (`TONE-HEDGE-VERDICT`) | 어느 쪽인지 한 문장으로 먼저 말하고, 예외는 조건으로 따로 적는다 | 대화 답변 |
| 경고 | 할 말을 예고하기 (`TONE-ANNOUNCE`) | 예고 문장을 지우고 첫 번째 내용부터 쓴다 | 대화 답변, 일반 글 |
| 경고 | 결과물 앞 안내 문장 (`TONE-META-PREAMBLE`) | 안내 문장 없이 결과물 본문부터 시작한다 | 전체 |
| 경고 | 더 해 드리겠다는 마무리 (`TONE-OFFER-MORE`) | 마지막 제안 문단을 지운다. 꼭 필요한 정보가 빠졌으면 답 앞에서 가정을 밝힌다 | 전체 |
| 경고 | 되묻기로 끝맺기 (`TONE-ASK-BACK`) | 되묻기를 지운다. 전제가 필요하면 답 앞에서 가정을 한 줄로 밝힌다 | 대화 답변 |
| 검토 | 덕담·응원으로 마무리 (`TONE-WELLWISH`) | 송별·축하 글이 아니면 덕담 문장을 지운다 | 일반 글, 공문·안내문, 제안서·보고서 |

## 글 틀

| 등급 | 틀 | 고치는 방법 | 적용 장르 |
|---|---|---|---|
| 경고 | 「단순한 A가 아니라 B」 격상 대비 (`FRAME-NOT-JUST`) | '단순히 A가 아니라'를 지우고 B를 구체적 사실로 바로 쓴다 | 전체 |
| 검토 | 「X는 A가 아니라 B다」 재정의 문장 (`FRAME-APHORISM`) | 한 글에 한 번까지만 쓴다. 문단 마지막 줄이면 지우고 사실 하나로 끝낸다 | 전체 |
| 경고 | 「중요한 것은 / 핵심은 / 성패는 ~에 달려 있다」 (`FRAME-KEY-IS`) | 안내어를 지우고 그 내용을 주어로 삼아 바로 쓴다 | 전체 |
| 경고 | 「결론적으로 / 요약하면 / 한 줄 요약」 (`FRAME-WRAPUP`) | 요약 문단을 지우거나 새 정보가 있는 문장으로 끝낸다 | 전체 |
| 검토 | 문장 머리 「결국」 (`FRAME-FINALLY`) | 마지막 문단의 '결국'은 지운다. 이야기 흐름 속 '결국'은 둔다 | 전체 |
| 경고 | 스스로 묻고 답하기·청중에게 묻기 (`FRAME-SELF-QA`) | 질문을 지우고 답을 평서문으로 쓴다. 도입은 실제 장면이나 수치로 연다 | 전체 |
| 경고 | 「작은 실천·첫걸음·한 걸음씩」 교훈 (`FRAME-SMALL-STEP`) | 교훈 대신 구체적 행동(무엇을, 언제, 얼마나)을 쓴다 | 전체 |
| 경고 | 은유 명사로 격상 (`FRAME-GRAND-NOUN`) | 은유 명사를 지우고 실제 효과를 사실로 쓴다 | 전체 |
| 검토 | 「~을 배웠다·깨달았다」 교훈 선언 (`FRAME-LESSON`) | 배운 점 선언 대신 그 뒤 실제로 달라진 행동을 쓴다 | 일반 글, 자기소개서 |
| 검토 | 다짐·포부로 끝내기 (`FRAME-RESOLVE`) | 다짐 문장을 지우거나 구체적 계획(무엇을 언제까지)으로 바꾼다 | 일반 글, 자기소개서 |
| 검토 | 「이것만 지켜도」 과장 약속 (`FRAME-ONLY-THIS`) | 근거 없는 효과 약속을 지우거나 출처 있는 수치로 바꾼다 | 전체 |
| 검토 | 「~이 달라집니다」 변화 선언 (`FRAME-CHANGES`) | 무엇이 어떻게 바뀌는지 한 가지를 구체적으로 쓴다 | 전체 |
| 검토 | 「A와 B 사이」「A인가 B인가」 제목 (`FRAME-TITLE-BETWEEN`) | 제목에 글의 실제 주장이나 대상을 쓴다 | 일반 글 |

## 어휘

| 등급 | 틀 | 고치는 방법 | 적용 장르 |
|---|---|---|---|
| 경고 | 「진심으로」 남발 (`VOCAB-SINCERE`) | 사과문에서 한 번은 둔다. 그 밖에는 지우고 무엇이 고마운지 사실로 쓴다 | 전체 |
| 경고 | 따뜻한·소중한 감성 형용사 (`VOCAB-WARM`) | 형용사를 지우고 무엇이 어땠는지 보이는 사실을 쓴다 | 일반 글, 자기소개서, 공문·안내문 |
| 경고 | 「진정한·진짜·참된」 강조 (`VOCAB-TRUE`) | 강조어를 지운다 | 전체 |
| 경고 | 「함께 성장·열정」 상투어 (`VOCAB-GROWTH`) | 무엇을 배우고 싶은지, 무엇을 할 줄 아는지 구체적으로 쓴다 | 자기소개서, 공문·안내문, 일반 글 |
| 검토 | 보도·홍보 상투구 (`VOCAB-PR-CLICHE`) | 행사 날짜·장소·프로그램 같은 사실로 바꾼다 | 공문·안내문, 일반 글 |
| 검토 | 후기 감각 상투구 (`VOCAB-SENSORY-BLOG`) | 그 가게·그 사람에게만 해당하는 관찰로 바꾼다 | 일반 글 |
| 검토 | 감상 부사 「새삼·괜히·어느새·오래오래」 (`VOCAB-FEEL-ADV`) | 부사를 지우고 그 감정이 든 계기를 쓴다 | 일반 글 |
| 검토 | 「~적·~적 특징을 지니다」 추상 수식 (`VOCAB-ABSTRACT-FEATURE`) | -적 수식을 걷어 내고 '단점도 뚜렷하다'처럼 바로 서술한다 | 전체 |
| 검토 | 뜻이 흐린 평가어 (`VOCAB-VAGUE-EVAL`) | 무엇이 얼마나 다양한지, 무엇에 효과가 있는지 대상을 쓴다 | 전체 |

## 서식

| 등급 | 틀 | 고치는 방법 | 적용 장르 |
|---|---|---|---|
| 경고 | 굵은 글씨 (`FMT-BOLD`) | 굵게를 모두 풀고 문장 순서로 강조한다 | 대화 답변, 일반 글, 자기소개서 |
| 경고 | 이모지 (`FMT-EMOJI`) | 이모지를 지운다 | 전체 |
| 경고 | 대화 답에 소제목·표·구분선 (`FMT-CHAT-STRUCTURE`) | 대화 답은 문단 두세 개로 쓴다. 표·소제목은 요청받았을 때만 | 대화 답변 |
| 경고 | 팁·분량 꼬리표 (`FMT-TIP-FOOTER`) | 꼬리표를 지운다. 분량은 말하지 않는다 | 전체 |
| 경고 | 버전·옵션 메뉴 (`FMT-VARIANTS`) | 가장 맞는 한 벌만 쓴다 | 전체 |
| 검토 | 첫째·둘째·셋째 나열 (`FMT-ORDINAL`) | 순서가 실제로 중요할 때만 쓰고, 아니면 문단으로 잇는다 | 일반 글, 자기소개서 |
| 검토 | 영어 병기 괄호 (`FMT-EN-GLOSS`) | 독자가 원어를 알아야 할 때만 한 번 병기한다 | 전체 |
| 검토 | 느낌표 문장 (`FMT-EXCLAIM`) | 정보 글에서는 마침표로 바꾼다 | 일반 글, 공문·안내문, 대화 답변 |
