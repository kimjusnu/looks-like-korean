# 실제 원고 오탐 측정

검사 규칙을 실제 원고에 돌려 걸린 문장을 사람이 하나씩 읽고 판정한 기록이다.
원고는 공개할 수 없으므로 **수치와 오탐 유형만** 남긴다(`docs/BRANCHING.md` 코퍼스 규칙).

## 2026-09-29 · 말투 일치 검사(`check --genre proposal`)

- 대상: 공모 제안서·신청서 원고 59편, 5,273문장 (한 사람이 쓴 공모 원고, 공모마다 최신본 1편)
- 방법: 걸린 문장을 전부 읽고 「맞게 잡음 / 오탐」으로 판정

| 단계 | REG-MIX(경고) | REG-NOM(검토) |
|---|---|---|
| 첫 구현 | 79 | 157 |
| 부정 명사형(「~하지 않음」)·인용문 제외, 개조식 문서 예외 | 9 | 75 |
| 개조식 기호(◦ ㅇ ※ 등)·그림 설명·「이름: 값」 서식 칸 제외, 「최다」 같은 명사 끝 예외 | **8** | **45** |

최종 REG-MIX 8건 판정:

- 맞게 잡음 6건: 합쇼체 제안서 안의 해라체 문장 5건, 작업 메모 줄 1건
- 오탐 2건: 공모 서식이 미리 넣어 둔 해요체 질문 문구

처음 오탐의 대부분은 분류기가 「~하지 않음」「안 됨」을 해라체(plain)로 두는 설계에서 나왔다.
지표(`score`) 결과를 바꾸지 않기 위해 분류기는 그대로 두고, 말투 검사(`genre.py`)에서만
명사형으로 다룬다.

REG-NOM 45건은 대부분 합쇼체 문단 사이에 목록 기호 없이 끼어 있는 개조식 줄이다.
「검토」 등급으로 두고, 기호를 붙일지 서술문으로 끝맺을지 글쓴이가 정하게 한다.

**확인하지 못한 것:** 자기소개서·공문·화면 문구 장르는 아직 실제 원고로 재지 않았다.
