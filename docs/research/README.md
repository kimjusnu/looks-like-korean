# 문체 근거 조사 노트

사람이 쓴 것처럼 읽히는 한국어를 쓰게 돕는 스킬의 근거 자료다. 2026-09-29에 무료로 공개된
자료만 조사했다. 이 폴더의 결론이 스킬 규칙과 검사 엔진의 출발점이 된다.

| 노트 | 다루는 것 | 출처 |
|---|---|---|
| [`academic.md`](academic.md) | 한국어 AI 생성 글의 언어적 특징, 탐지 연구, 서로 충돌하는 주장 | 논문 25편 (한국어 11, 영어 14) |
| [`public-language.md`](public-language.md) | 국립국어원·행정 기관의 문장 지침, 자기소개서 지침, 장르별 말투 | 공개 자료 21건 |
| [`ux-writing.md`](ux-writing.md) | 앱·웹 화면 문구(버튼·오류·빈 화면·확인 창) 원칙과 말투 결정 절차 | 기업·기관·해외 가이드 29곳 |

## 이 폴더의 규칙

- **원문을 옮기지 않는다.** 원칙은 모두 요약해서 적었고, 직접 인용은 출처당 15단어 미만 한 번까지만 허용한다.
- **예문은 모두 새로 지었다.** 출처의 예문을 가져오지 않는다.
- **내려받은 PDF와 추출 텍스트는 저장소에 넣지 않는다.** 출처 목록의 URL로 확인한다.
- 노트마다 「본문까지 읽음 / 초록·일부만 읽음」을 표시했다. 근거 강도를 볼 때 이 표시를 함께 본다.

## 설계에 반영하는 결론

1. **종결어미를 다양하게 바꾸라고 지시하지 않는다.** 산문에서 이를 지지하는 연구는 찾지 못했고,
   반대 방향 근거가 있다. 이 저장소의 v0.1.0도 7쌍 모두에서 실패했다. 같은 어미가 길게 이어지면
   다시 읽을 곳으로 표시만 한다. (`academic.md` C1)
2. **장르를 먼저 정한다.** 자기소개서, 제안서·보고서, 공문·안내문, 화면 문구는 맞는 말투와 규칙이 다르다.
   세 노트가 모두 같은 결론을 낸다. (`public-language.md` 4장, `ux-writing.md` 4장)
3. **자기소개서는 어투보다 내용이 문제다.** 채용 현장에서 AI 자기소개서를 감점하는 주된 사유는
   독창성 부족이다. 문장마다 본인의 행동·장면·수치가 있는지 확인하는 단계가 필요하다. (`public-language.md` 3장)
4. **기계 검사는 근거가 강한 신호만 경고한다.** 연결어미 뒤 쉼표, 번역 투 3종, 상투적인 틀, 줄표,
   명령형 명사 종결이 여기에 해당한다. 정상 쓰임이 많은 낱말은 검토 권고로 낮춘다.
5. **번역 투는 AI 탐지 규칙이 아니라 품질 규칙이다.** LLM 이후 오히려 줄어든 표지도 있다. (`academic.md` C3)

## 확인하지 못한 것

- 노트에 적힌 정규식은 모두 초안이다. 실제 글에 돌려 오탐률을 잰 적이 없다.
- 일부 공공 자료는 공공누리 유형을 확인하지 못했다. 대조표 같은 원문 표를 옮기기 전에 먼저 확인한다.
- 한국어 화면 문구와 AI 문체를 직접 다룬 학술 연구는 찾지 못했다. 화면 문구 규칙의 근거는 실무 자료다.
