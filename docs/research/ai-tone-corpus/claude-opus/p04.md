# 지원 동기

대학에서 컴퓨터공학을 공부하며 두 번의 팀 프로젝트를 진행하는 동안, 제가 가장 큰 성취감을 느꼈던 순간은 코드 몇 줄이 실제 사용자의 불편을 해소하는 장면을 확인했을 때였습니다. 첫 프로젝트에서는 학내 중고거래 웹 애플리케이션의 백엔드 API를 맡아 데이터베이스 설계와 인증 로직을 구현했고, 두 번째 프로젝트에서는 팀 리더로서 지역 소상공인을 위한 재고 관리 서비스를 기획부터 배포까지 완주했습니다. 두 경험 모두 기술적 완성도만큼이나 사용자의 문제를 정확히 정의하는 일이 중요하다는 사실을 배우게 해 주었습니다.

귀사가 지향하는 「사용자 중심의 서비스」라는 방향성은 제가 프로젝트를 통해 체득한 개발 철학과 정확히 맞닿아 있다고 느꼈습니다. 특히 안정적인 아키텍처 위에서 빠르게 실험하고 개선해 나가는 개발 문화, 그리고 신입에게도 주도적으로 기능을 맡기는 성장 환경은 제가 오래 몸담고 싶은 조직의 모습이었습니다.

아직 실무 경험은 부족하지만, 팀 프로젝트에서 몸으로 익힌 협업 감각과 끝까지 제품을 완성해 낸 책임감은 어떤 환경에서도 빠르게 적응할 수 있는 저의 자산이라고 자신합니다. 배우는 자세로 합류하여 작은 기능부터 견고하게 만들어 내는 개발자로 성장하고, 나아가 귀사의 서비스가 더 많은 사용자에게 신뢰받는 데 기여하고 싶어 지원하게 되었습니다.
