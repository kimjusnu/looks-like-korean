# 중고 거래 앱에서 사기를 피하는 방법

중고 거래는 알뜰한 소비 방법이지만, 그만큼 사기 위험도 존재합니다. 안전한 거래를 위해 반드시 알아두어야 할 핵심 수칙을 정리했습니다.

## 1. 거래 전, 판매자/구매자 신원 확인하기

**계정 정보를 꼼꼼히 살피세요.**
- 가입일이 최근이거나 거래 이력이 거의 없는 계정은 주의
- 매너 온도, 후기, 재거래 희망률 등을 확인
- 프로필 사진, 닉네임, 활동 지역이 일관성 있는지 확인
- 여러 지역에서 동시에 판매글을 올리는 계정은 의심

**사기 이력 조회 사이트를 활용하세요.**
- '더치트(thecheat.co.kr)', '사이버캅' 등에서 계좌번호와 전화번호를 조회
- 조회 결과가 없더라도 완전히 안전하다고 단정하지는 마세요

## 2. 게시글에서 사기 징후 파악하기

- **시세보다 지나치게 저렴한 상품**은 대부분 미끼입니다
- 인터넷에서 흔히 볼 수 있는 제품 사진을 사용한 경우 의심
- "급처", "오늘만", "선입금 시 할인" 등 조급함을 유발하는 표현
- 구매 문의에 실물 사진 요청 시 회피하거나 흐릿한 사진만 보내는 경우
- 상품 설명이 지나치게 간략하거나 어색한 번역체

## 3. 실물 사진과 영상 요청하기

- 게시글의 사진 외에 **추가 실물 사진**을 요청하세요
- 요청 시 **특정 포즈**(예: "본인 손과 함께 찍은 사진", "오늘 날짜가 적힌 종이와 함께")를 지정
- 가능하다면 짧은 **영상 통화**로 실물 확인
- 사진을 거부하거나 이미 인터넷에 있는 사진을 재활용하는 경우 거래 중단

## 4. 안전한 결제 수단 사용하기

**직거래를 최우선으로**
- 사람이 많은 공공장소(지하철역, 편의점 앞 등)에서 낮 시간에 만나기
- 상품 상태를 직접 확인한 뒤 결제

**택배 거래 시에는 반드시 안전결제 이용**
- 당근페이, 번개페이, 네이버페이 안전거래 등
- 판매자가 안전결제를 거부하고 **계좌이체만 요구**하면 사기 가능성 높음
- "수수료가 아까우니 계좌로 보내달라"는 요청은 거절

## 5. 개인정보와 링크 조심하기

- **문자, 카톡으로 온 결제 링크**는 절대 클릭 금지 (피싱 사이트 위험)
- 앱 내 채팅에서 외부 메신저(카톡, 텔레그램)로 유도하는 경우 주의
- 신분증, 계좌 사진 등을 요구하는 경우 거절
- 안전결제를 사칭한 가짜 사이트 URL 주의 (공식 도메인과 다른 철자)

## 6. 택배 거래 시 유의사항

- 송장 번호를 미리 요청하고 실제 배송 조회 가능한지 확인
- 반값택배, 편의점 택배 등 익명 배송 시 특히 주의
- 상품 수령 후 즉시 개봉해 상태 확인 (개봉 영상 촬영 권장)
- 벽돌, 휴지 등 엉뚱한 물건이 왔다면 즉시 신고

## 7. 사기를 당했다면

1. **증거 확보**: 채팅 내역, 계좌번호, 송금 내역, 게시글 캡처
2. **경찰 신고**: 사이버수사대 또는 가까운 경찰서에 방문 접수
3. **경찰청 사이버범죄 신고시스템(ECRM)** 온라인 접수 가능
4. **해당 앱 신고**: 당근마켓, 번개장터 등 플랫폼 내 신고 기능 활용
5. **더치트에 등록**: 다른 피해자를 막기 위해 사기 정보 공유

## 마무리

중고 거래의 핵심은 **의심스러우면 거래하지 않는 것**입니다. 조금이라도 이상한 낌새가 느껴지면 아쉬워하지 말고 거래를 중단하세요. "이 가격이 말이 되나?" 싶은 상품은 대부분 사기입니다. 안전결제와 직거래라는 두 가지 원칙만 지켜도 대부분의 사기를 예방할 수 있습니다.
