# 실패 기록 — 종결 uniformity를 낮추는 재작성은 글을 망쳤다

> **이 문서는 더 이상 데모가 아니다.** v0.1.0 에서는 「after 가 낫다」는 근거로 실렸으나,
> 한국어 원어민이 판단했고 틀렸다. 아래는 그 근거 자료다.
> 전체 7쌍은 [`../eval/counterexamples.json`](../eval/counterexamples.json).

## 요약

| 쌍 | 장르 | `uniformity_index` | 화자의 판정 | 실제 결함 |
|---|---|---|---|---|
| ex-01 | 메모 | 1.000 → 0.130 | **after 가 나쁨** | 오지 않은 대화를 지어냄 |
| ex-02 | 자기소개 | 1.000 → 0.086 | **after 가 나쁨** | 반말로 끝남 |
| ex-03 | 제안서 | 1.000 → 0.125 | **after 가 나쁨** | 기관에 보낼 문서에 해요체 |
| ex-04 | 리포트 | 1.000 → 0.015 | **after 가 나쁨** | 반말 + 파조문 |
| ex-05 | 블로그 | 1.000 → 0.041 | 미확정 | 반말이 장르에 맞음 |
| ex-06 | 에세이 | 1.000 → 0.077 | 미확정 | 반말이 장르에 맞으나 개선인지 미분 |
| ex-07 | 메모 | 1.000 → 0.041 | **after 가 나쁨** | 동료에게 반말 |
| ex-08 | 제안서 | 1.000 → 0.033 | **after 가 나쁨** | 한 문서 안에서 레지스터 파괴 |
| ex-09 | 리포트 | 1.000 → 0.083 | **after 가 나쁨** | 공적 보고에 「~낮더라고요」 |

7쌍 전부에서 `uniformity_index` 는 떨어졌다(1.000 → 0.015~0.130). **7쌍 전부에서 글은 나빠졌다.**

## 세 쌍 전문

### ex-01 · 메모

**before — AI처럼 쓴 원고.** 읽히고 명확하고 무난하다. 결함은 없지만 지루하다.

> 회의 시간이 변경되어 안내드립니다. 이번 주 목요일 회의는 오후 3시에서 오전 11시로
> 앞당겨집니다. 장소는 3층 소회의실로 변경되었습니다. 관련 자료는 회의 시작 전까지 각자
> 확인해 주시기 바랍니다. 일정이 어려운 분은 오늘까지 회신해 주시면 일정 조정이
> 가능하겠습니다. 안내해 주셔서 감사합니다.

**after — 지표를 낮추려고 고친 것.**

> 회의 시간이 갑자기 앞당겨져서 먼저 공지해 **둡니다**. 이번 주 목요일 건만 11시로
> 당겼고, 나머지 주는 **그대로예요**. 장소도 3층 소회의실로 **바뀝니다**. 자료는 미리
> 보내둘 테니 전에서 한 번 읽고 **오세요**. 시간이 안 되는 분은 오늘 안에 톡만 남겨 주시면
> **됩니다**. …

**결함** — 「있나요? 네, 그럼 이대로 갑니다」는 실제로 오간 대다. 계측값이
레지스터를 다르게 만들라고 지시했을 뿐, 그 지시를 수행하려고 **존재하지 않는 화자**를
발화했다. 이 한 줄이 나머지 여섯 쌍의 축약이다.

### ex-03 · 제안서

**before** — 「아파트 단지 앞 보행로 개선 방안을 제안드립니다. 현재 해당 구간은 포장 파손이
심하고 야간 조도가 부족한 상황입니다. … 관리사무소 검토 후 반영해 주시면 감사하겠습니다.」

**after** — 「단지 앞 보행로 좀 봐 주시겠어요? 저녁에 내려갈 때마다 어두워서 불안한데,
가로등 하나가 안 들어와요. …」

**결함** — 독자는 주민이 아니라 관리사무소다. 해요체와 구어 존칭이 **지위를 낮췄다.**
「아무리 ~하더라도」 같은 완충 표현은 결함이 아니라 한국어 제안서의 관용구였다.

### ex-06 · 에세이

**before** — 「이러한 반복은 무의식적으로 안정감을 부여하는 효과를 낳습니다. 그러나 이
안정이라는 감각은 정체와 구분하기 어렵습니다. …」

**after** — 「6분이면 알람 하나로 충분한데 어느새 10분이 되더라. 이게 일상이 되면 별생각을
안 하게 되는 것이 문제임. 그래서 더 못 느끼고 더 못 느끼니까 더 안 돌아보게 되고. …」

**판정 보류** — 1인칭 에세이에 반말은 맞다. 다만 이것이 「리듬 개선」인지 「장르에 맞게
쓴 것」인지 구분할 근거가 없다. 구분하려면 화자의 정지 기준이 필요하다.

## 여기서 확정되는 것

1. **`uniformity_index` 는 품질 지표가 아니다.** 다양성을 잰다. 그리고 다양성 ≠ 품질.
2. **지표를 낮추려고 글을 고치는 순간 지표가 목표가 된다.** 7쌍의 공통 원인.
3. **한국어 윤문의 진짜 실패 모드는 결함 잔존이 아니라 장르 위반 도입이다.** 그것을
   측정하는 도구는 아직 없다.
4. 다음 단계는 지표가 아니라 **화자 선호 쌍 데이터**다. 근거는
   [`RESEARCH.md`](RESEARCH.md) 와 README 「What we need next」.
